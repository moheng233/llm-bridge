# LLM Bridge Frontend

Vue 3、TypeScript、Vite、Tailwind CSS 与 Reka UI。开发及后端联调方式见仓库根目录 README。

## 页面布局

应用使用固定视口外壳（`100dvh`，回退 `100vh`）。文档、`#main-content` 和 PageShell 外框不滚动，不通过隐藏滚动条或裁掉内容解决高度问题。

- 顶部 App header 是唯一的页面标题与面包屑入口：父级为可点击导航，当前页带 `aria-current="page"` 并保留唯一的 H1。详情名称异步更新后同步到顶部，正文不再重复展示标题或领域图标。
- PageShell 的 `header`、`toolbar`、`footer` 插槽分别放业务状态/操作、主要筛选及分页/主操作，固定区域不能随列表长度增长。列表总数仅在分页栏展示，不在页头重复计数或单独占行；没有元信息或操作的页头自动消除占位。
- 单个创建按钮或筛选控件不再独占正文上方一行。列表创建入口放入 ListToolbar 的 `actions` 插槽，与搜索、刷新同排；没有搜索栏的概览日期选择通过 Teleport 放入 App 的 `#page-header-actions`，保留页面自身的状态与查询逻辑，离开页面时卸载。
- 默认插槽是正文，默认独立滚动；概览、请求详情、简单卡片列表使用此模式。`body-class` 可补充正文布局。
- 多栏工作区和内部自带滚动的表格使用 `:scrollable="false"`，由正文子组件接收剩余高度。每层 Flex/Grid 均须有 `min-h-0`/`min-w-0`，弹性 Grid 轨道使用 `minmax(0,1fr)`，不能用内容高度撑开父层。
- CatalogPicker、ConnectionList、ProviderForm 的 `fill` 模式填充父层分配的空间，分别固定搜索/分页或表单底栏。自然流模式适用于已经存在正文滚动容器的嵌入场景，避免不必要的嵌套纵向滚动。
- ProviderForm 的 `before-fields`、`after-fields` 插槽位于滚动正文中，但在禁用字段集合之外，供恢复操作、状态与删除区域使用。`actions` 仍位于固定底栏；非提交按钮必须保留 `type="button"`。
- Table 的 `class` 作用于表格本身，`container-class` 作用于实际滚动包装。表头 sticky 必须对应这个包装，不能把 tbody 改成 block 来固定表头。
- PageFilters 在手机或低高度窗口内把次要筛选收进有界弹出层，筛选状态由页面持有。ListToolbar 的 `collapse-filters`（传给 PageFilters 的 `collapsed`）可让筛选在所有尺寸下都通过工具栏入口展开。接入页保留桌面双栏、手机标签和低高度紧凑工具栏；切换布局不能重建草稿或改变选择。
- 纵向滚动正文使用 `data-scroll-area` 和 `overscroll-contain`。错误聚焦使用 `focusInScrollArea`：展开祖先 details、保留外框滚动位置，只调整所属正文。异步标签切换后先等待 `nextTick`。
- Dialog/Sheet 的正文可以滚动，背景不能滚动；标题与必要操作保持可达。代码块、宽表格允许内部横向滚动，但不能撑宽页面。

## 页面一致性

- SectionHeader 的 `title` 通过 `usePageHeader` 提供给 App 的面包屑，不在正文渲染第二份标题；下方仅展示业务状态、`subtitle` 中的业务 ID 与主操作，不显示列表数量标签。标题状态由 App 局部提供，组件卸载清理所属标题，页面加载或无权限时使用对应路由的回退标题。父级返回统一使用顶部 RouterLink，仍受未保存修改保护。
- ListToolbar 固定搜索、清除筛选、刷新入口，`actions` 插槽承载同排创建操作；复杂筛选沿用 PageFilters 的响应式展开方式。搜索不区分大小写并忽略首尾空白；刷新保留当前筛选，搜索或筛选变化回到第一页。服务端请求记录保留原搜索防抖和查询参数。
- 本地列表先过滤及排序，再用 useListPagination 每页显示 50 项；结果减少时自动回退到有效页。ListPagination 统一使用从 1 开始的页码及首/前/后/末页控件，显示当前范围和总数；请求记录仅在页面边界转换为后端从 0 开始的页码。
- PageShell 的 `reset-key` 随查询和页码变化，重置所属正文滚动位置，不滚动页面外框。刷新不清除搜索、草稿或当前有效页；连接详情刷新保留列表组件实例。
- 卡片记录统一用 ListItem 的标题、状态、业务 ID、摘要和操作插槽。使用模型与访问令牌在桌面和手机均使用该卡片及 PageShell 默认滚动正文，不再为模型单独套滚动层或切换桌面表格。模型筛选与排序在所有尺寸下通过工具栏入口展开，保留能力、路由状态、价格及 Token 上限。名称可进入查看/编辑；非交互正文不整行跳转，复制内容不会误导航。请求记录保留适合扫描的表格，行尾提供显式“查看”。
- 主创建操作使用主色和加号，与搜索控件同排；移动端最小高度 44px、桌面 36px，使用 `transition-colors` 避免断点变化时动画改变高度。查看/编辑、启停使用 outline，危险移除使用低强调的危险色并放在末尾。禁用和能力声明不混为一谈，启用连接不表示实时上游可达。
- 空态使用 EmptyState；筛选无结果提供清除入口，尚无记录的创建入口与工具栏指向同一流程。加载使用相同骨架和 `role="status"`，错误使用 ErrorState 的 `role="alert"`；表单错误不截掉必要信息。
- 概览成功返回零请求时仍展示零值指标、空趋势图、模型排行和最近请求区域，不用模型配置引导替换统计，也不额外展示“全站用量 / 管理员视角”一行。概览不依赖可用模型查询；加载和接口失败保持独立反馈，不将查询失败伪装成零数据，未知延迟仍显示为未知。
- 管理员在概览顶部日期选择旁使用“全站 / 我的”tab，默认全站；成员隐藏范围切换并始终查询本人。汇总与最近请求一起携带 `scope=all|mine`，日期切换不改变范围。切换时清空旧指标，仅最后一次请求可更新数据或错误，避免快速切换、重试或身份变化混入旧范围结果。“查看全部”跳转到同范围的请求列表；列表范围切换回第一页，清除其他筛选不改变范围。服务端仍独立校验全站权限。
- 令牌与模型连接使用一致的编辑侧栏：固定标题、内部滚动字段、底部“取消 / 保存修改”。复杂的提供者与模型定义继续使用详情页面，接入向导继续保留两次保存检查点，不为视觉一致改变业务结构。
- 未保存取消使用“放弃未保存的修改？”和“放弃修改”；删除/移除明确展示影响并要求“确认删除 / 确认移除”。取消不写入，保存失败保留输入，保存或移除后刷新数据并保持有效分页。刷新/提交期间防止重复操作。
- 令牌首次明文展示、模型范围、配额默认值、用户角色修改确认及个人权限处理保持独立业务约束。一次性令牌关闭前仍要求确认保存；不把凭据写入 URL 或浏览器持久存储。

## 验证

在 frontend 目录执行 `pnpm run build`、`pnpm run lint`，对改动文件执行 `pnpm exec oxfmt --check <files>`。构建先运行 Vite 生成自动声明，再运行 vue-tsc；不要手改生成绑定。

绑定使用 `cargo xtask bindings` 生成、`cargo xtask bindings --check` 校验，执行前先安装前端依赖（`pnpm --dir frontend install --frozen-lockfile`）。生成与校验共用前端 oxfmt 配置；校验只格式化临时导出文件，再与仓库逐字节比较，不改写已有绑定。

布局变更还必须检查真实浏览器，编译成功不代表滚动正确：

- 使用至少 51 条模拟列表记录，覆盖目录/表格/卡片、长表单、长详情、加载、空和错误状态；不要为通过测试减少原分页条数。
- 桌面 1440x900、1024x768，手机 390x844、360x640，横屏 844x390；检查 768px/1024px 断点、200% 缩放与实际移动软键盘。简单 resize 不能证明软键盘行为。
- 文档、main、页面外框的 scrollHeight/scrollWidth 不得超出 clientHeight/clientWidth（允许 1px 舍入）；指定正文应有可操作高度，长数据必须能滚到末项。
- 标题去重检查覆盖列表、创建、详情、加载与页面切换：已登录页面只在顶部面包屑保留一个 H1，main 中没有重复 H1；长名称截断不能遮住导航和搜索，父级链接必须保留草稿离开确认。
- 操作区合并后需检查原页头行高度为零、搜索与创建按钮同排、创建/取消流程不变；概览日期控件切换仍使用原查询参数，离开概览后不得残留到其他页面的顶部。
- 实际滚轮、键盘翻页和焦点移动只改变正文 scrollTop；页头、分页和操作栏位置不变，末尾字段与按钮不被遮挡。
- 表单校验要覆盖非当前标签与折叠高级字段；搜索、分页、已选项和草稿在标签/断点切换后保留，离开确认取消后保持原值。
- 一致性变更还需逐列表检查搜索后回第一页、刷新保留筛选、空态和错误态、末页删除后的页码回退；编辑侧栏检查取消确认、保存失败保留草稿及令牌一次性明文保护。
- 模型与令牌页对齐检查使用相同数量的记录，对照工具栏高度、正文起点、卡片间距和分页位置；确认折叠筛选重新打开后状态保留、排序在分页之前执行，详情中仍能查看能力覆盖与接入方式。
- 概览需覆盖零请求、有数据、统计接口失败和最近请求接口失败；零请求仍保留图表区域，接口错误必须可见且不能伪造零值统计。
- 统计范围需验证管理员全站/本人、成员仅本人、降权后的权限、上一周期和最近请求隔离，以及全站/本人/全站快速切换时旧成功或旧错误响应不能覆盖最新结果；tab 键盘操作、日期联动和“查看全部”范围传递均需回归。
- 用会话内接口夹具验收长数据与保存结果，不调用真实上游，不向数据库批量写测试记录；解除拦截后恢复原页面与视口。
